## Decisions confirmed 2026-09-16 (Modules A+B integrated system + production build — doc/23)

> Production work started on Modules A+B (user directive). Design in `doc/23`; implementation in
> `module-a/media/` and `kiosk/`. These are engineering decisions; thresholds/rules/model bindings
> remain placeholders pending M0 and clinical sign-off.

| Decision | Choice | Why |
|---|---|---|
| Kiosk concurrency model | **Single-slot scheduler: exactly one heavy stage resident at a time**, guarded by a memory watchdog; stage leases granted by priority | A and B share one CPU/RAM; naive threading would co-run ASR+OCR+LLM and violate the hard constraint (doc/09 §6, doc/23 §3.4). | A↔B preemption | **A always preempts B at a page boundary**; B is page-atomic so preemption can never half-extract a document | A is on the patient-conversation critical path, B is batch (doc/23 §2.2); page-atomicity preserves the confidence gate's unit of evaluation |

| Shared LLM runtime | **One Qwen3 runtime shared by A-NLU and B-structurer, load-on-demand, evicted under memory pressure; not kiosk-resident on 4 GB** | RAM contention is the largest shared dependency; on 4 GB the deterministic rules floor runs instead (doc/23 §4.3/§4.4) |
| Compute placement | **Minimal kiosk-resident set (VAD, ASR, FSM, red flags, TTS, OCR, deterministic structurer); LLM structuring and FHIR validation/ABDM on the edge**; recommended combined kiosk = **8 GB**, 4 GB = reduced profile | Offline-first forces local OCR; LLM structuring is the only heavy stage that is safely edge-offloaded (doc/23 §4.4, AB-D2/D5) |
| Degradation policy | **A stage that cannot be admitted is skipped and recorded; the deterministic floor still runs; the encounter is never failed** | Invariants 2 and 7: never fabricate, never block care. Verified on the 4 GB profile (`A_NLU` degraded, identical clinical counts) |
| Module B integration contract | **Additive `medib.pipeline.run(page_guard=...)`** hook (a zero-arg callable returning a context manager held per page); no other `module-b` change | Lets the kiosk hold a per-page lease without Module B knowing about the scheduler, preserving single-source-of-truth merge logic and all existing tests |
| Module A output | **`media` emits `medikiosk-history-bundle/1` directly, mirroring `medic.contracts` field-for-field** | Producer parity removes any adapter; verified by a round-trip test through `load_history` |
